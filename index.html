PERTANYAAN UMUM

Frequently Asked Questions

Semua hal yang perlu Anda ketahui tentang implementasi software, arsitektur data, dan layanan FINTEGRITA.

01 Apakah software FINTEGRITA bisa disesuaikan dengan SOP & AD/ART lembaga kami?
Bisa. Alur persetujuan (approval multilevel), skema bunga pinjaman (flat, efektif, menurun), biaya administrasi, hingga format pencetakan laporan RAT dapat dikustomisasi sesuai aturan main dan AD/ART lembaga Anda, baik skema SaaS maupun Agency.
02 Apa perbedaan model berlangganan (SaaS) dan pembuatan khusus (Agency)?
Model SaaS menggunakan sistem siap pakai berbasis cloud dengan biaya awal terjangkau, update sistem gratis, dan perawatan server ditanggung FINTEGRITA. Model Agency (Custom) ditujukan untuk lembaga yang ingin kustomisasi alur unik, arsitektur server on-premise sendiri, atau kepemilikan source code penuh.
03 Bagaimana FINTEGRITA menjamin keamanan dan kerahasiaan data nasabah?
Kami menerapkan arsitektur Tenant Siloed Database di mana database tiap instansi terisolasi total dan tidak bercampur. Seluruh transmisi data dienkripsi dengan protokol TLS 1.3 / AES-256, serta dilengkapi log aktivitas audit trail yang tak dapat dimanipulasi.
04 Apakah bisa migrasi dari pembukuan Excel atau catatan fisik lama?
Bisa. Tim teknis FINTEGRITA mendampingi proses validasi dan impor data awal (daftar anggota, saldo simpanan, baki debit pinjaman berjalan, dan data produk) langsung dari format spreadsheet Excel ke dalam database sistem baru.
05 Apakah staf dan pengurus kami mendapatkan pelatihan langsung?
Ya. Paket implementasi sudah termasuk sesi pelatihan (onboarding) langsung bagi pengurus, bendahara, dan operator kasir. Kami juga menyediakan panduan video, modul SOP ringkas, serta dukungan konsultasi akuntansi berstandar SAK.
06 Berapa lama proses implementasi hingga sistem siap pakai (Go-Live)?
Untuk paket standar (SaaS Koperasi dan Website Profil), deployment dan setup awal memakan waktu 3–7 hari kerja setelah data siap. Untuk kebutuhan sistem custom enterprise berskala besar, rata-rata pengerjaan berkisar antara 2–4 minggu.
